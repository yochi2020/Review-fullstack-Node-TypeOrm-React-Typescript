# ตัวอย่าง Agent สำหรับการเรียนรู้

โฟลเดอร์นี้จัดทำขึ้นเพื่อแสดงตัวอย่างการจัดเก็บ role prompt ที่นำกลับมาใช้ซ้ำได้ สำหรับทีมหรือระบบ agent runner ที่พัฒนาขึ้นเอง

ข้อสำคัญ: Codex **ไม่ได้** ค้นหาหรืออ่านคำสั่งจาก `.agents/` โดยอัตโนมัติ คำสั่งของ Codex ที่มีผลทั้ง Repository ต้องอยู่ใน `AGENTS.md` ที่ root เก็บโฟลเดอร์นี้ไว้เฉพาะเมื่อมีเครื่องมือหรือ workflow ของคุณอ่านไฟล์เหล่านี้

ไฟล์ตัวอย่างภายในโฟลเดอร์นี้เป็น role card ไม่ใช่ configuration ที่ทำงานได้ด้วยตัวเอง:

- `frontend-reviewer.md` ใช้กำหนดแนวทางตรวจ React และพฤติกรรมใน browser
- `backend-reviewer.md` ใช้กำหนดแนวทางตรวจความถูกต้องและความปลอดภัยของ API

หากต้องการใช้ด้วยตนเอง ให้สั่ง Agent ปฏิบัติตามทั้ง `AGENTS.md` และ role card ที่เลือก หากไม่ใช้ตัวอย่างเหล่านี้ สามารถลบโฟลเดอร์ `.agents/` ทั้งหมดได้อย่างปลอดภัย
